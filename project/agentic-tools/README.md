# agentic-tools
The agentic tools are components that standardize the ability of agents and/or apps to connect to resources in consistent and predictable methods.  The tools are as follows:

##Tool Outline
edgar_tool.py is a set of Python-based tools that is the basis to connect to the SEC's EDGAR financial database. It is the source of public reporting for companies listed on US stock exchanges.
edgar_mcp_server.py is the MCP server that calls the edgar_tool.py.
